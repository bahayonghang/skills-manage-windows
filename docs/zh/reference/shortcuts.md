# 快捷键

跨平台快捷键，由 `react-router` 与全局命令面板提供。Windows / Linux 上的 `Ctrl` 在 macOS 对应 `Cmd`。

## 全局

| 快捷键 | 动作 |
| --- | --- |
| `Ctrl+K` / `Cmd+K` | 打开命令面板 |
| `Ctrl+/` | 聚焦全局搜索 |
| `Ctrl+,` | 打开设置 |
| `Esc` | 关闭对话框 / 抽屉 / 命令面板 |

## 导航

| 快捷键 | 动作 |
| --- | --- |
| `g` 然后 `c` | 跳转中央技能库 |
| `g` 然后 `p` | 跳转平台（最近访问） |
| `g` 然后 `m` | 跳转 Marketplace |
| `g` 然后 `d` | 跳转 Discover |
| `g` 然后 `s` | 跳转设置 |
| `Alt+←` | 浏览器后退 |
| `Alt+→` | 浏览器前进 |

## 技能详情

| 快捷键 | 动作 |
| --- | --- |
| `e` | 编辑技能元数据（条件允许时） |
| `i` | 打开安装对话框 |
| `c` | 加入集合 |
| `r` | 从源重新刷新 |
| `o` | 在系统资源管理器中打开 |

## 列表

| 快捷键 | 动作 |
| --- | --- |
| `j` / `k` | 卡片列表上下移动焦点 |
| `Enter` | 打开聚焦卡片 |
| `Space` | 切换选择（多选场景） |

## 主题

| 快捷键 | 动作 |
| --- | --- |
| `Ctrl+Shift+L` | 循环切换 Catppuccin 风格 |
| `Ctrl+Shift+A` | 循环切换 accent 配色 |

## 注意

- `g` 组合键有 600 ms 超时，需在窗口内按下第二键，否则重置。
- 文本输入聚焦时键盘处理暂停，搜索框里输入 `g` 不会触发跳转。

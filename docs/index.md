    details: Browse curated publishers, sync registries, and import skills directly from any GitHub repository with PAT-authenticated requests.
  - title: SSH remote mode
    details: Connect to a remote Linux or macOS host over SSH and manage that host's global skills without leaving the desktop.

    details: English and Simplified Chinese interface, four Catppuccin flavors, accent colors, and onboarding. No telemetry.
  - title: Local-first, privacy-aware
    details: Metadata, settings, and AI explanation cache stay in a local SQLite database. Network calls only happen when you trigger them.

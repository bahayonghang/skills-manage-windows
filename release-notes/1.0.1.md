# SkillPort 1.0.1

### English

SkillPort 1.0.1 brings the current Update Center, Central Library, import,
diagnostics, and automation work together in a Windows-first desktop release.

#### Highlights

- Unify skill updates, remote additions and deletions, platform duplicates,
  scoped refreshes, retries, and cleanup decisions in the Update Center.
- Expand the Central Library with repository and source navigation, adaptive
  layouts, filters, inline tag editing, bulk actions, and SQLite-backed
  pagination for larger collections.
- Add target-aware Central state import and export for local, SSH, and WSL
  targets, with origin metadata and compatibility warnings.
- Strengthen GitHub and local ZIP imports with branch selection, bounded
  previews, selected-subtree import, safe archive fallbacks, and stable skill
  identities.
- Add the shared `skillport-cli` contract, runtime diagnostics, redacted log
  export, and improved operation failure details for desktop and automation
  workflows.
- Harden Central mutations and database migrations with transactional repair,
  versioned backups, scoped recovery, and recoverable filesystem/database
  operation records.
- Improve dashboard, usage, Central, and Platform interfaces with denser
  layouts, clearer status feedback, keyboard focus, and accessibility updates.
- Tighten credential, external-content, path, and renderer capability
  boundaries while expanding fail-closed CI and release verification.

### 中文

SkillPort 1.0.1 将更新中心、Central 技能库、导入、诊断和自动化能力集中到
一次 Windows-first 桌面版本发布中。

#### 亮点

- 通过更新中心统一处理技能更新、远端新增与删除、平台冗余、按范围刷新、失败
  重试和清理决策。
- 扩展 Central 技能库，新增仓库与来源导航、自适应布局、筛选、卡片内标签编辑、
  批量操作，以及面向大型技能库的 SQLite 分页。
- 新增按目标感知的 Central 状态导入与导出，支持本机、SSH 和 WSL 目标，并保留
  来源元数据和兼容性提示。
- 加固 GitHub 与本地 ZIP 导入，支持分支选择、受限预览、选中子树导入、安全
  archive 回退和稳定技能标识。
- 新增共享 `skillport-cli` 契约、运行时诊断、脱敏日志导出，以及面向桌面端与
  自动化工作流的操作失败详情。
- 通过事务化修复、版本化备份、按范围恢复和可恢复的文件系统/数据库操作记录，
  加固 Central 写操作与数据库迁移。
- 优化 Dashboard、Usage、Central 和 Platform 界面，提供更紧凑的布局、更清晰的
  状态反馈、键盘焦点和无障碍行为。
- 收紧凭据、外部内容、路径和 renderer capability 边界，并扩展 fail-closed CI
  与发布校验。

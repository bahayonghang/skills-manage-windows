# SkillPort 0.10.x

## 0.10.10

### English

SkillPort 0.10.10 is a larger desktop release that collects the Central Skills
workspace, update flow, platform coverage, runtime diagnostics, and backend
maintenance work accumulated after `v0.10.9`.

#### Highlights

- Redesign Central Skills with denser cards, repository navigation, colored tag
  pills, layout/density controls, and richer metadata sidebars.
- Add update-check modes and a unified Update Center that handles normal
  refreshes, forced mirror synchronization, remote additions, remote deletions,
  repository relocations, and platform duplicate cleanup from one flow.
- Add Central Skills repository search, source metadata, platform batch
  uninstall, deleted-platform-copy cleanup, and automatic same-repository
  same-ID path relocation handling.
- Add AI-assisted tagging controls, an AI Provider task cockpit, provider key
  links, and settings layout refinements.
- Add usage platform filtering, skill call-count sorting, a runtime log console,
  and runtime-log store tests.
- Add built-in Reasonix and Grok platform targets, while tightening updater
  platform gating for Windows-only in-app update metadata.
- Harden GitHub import resource budgets, fixture filtering, path normalization,
  remote WSL target refresh behavior, Windows CI command shims, and desktop
  release gates.
- Move heavy backend IO through `spawn_blocking`, convert many backend domains
  to typed `thiserror` errors, split large backend modules, and expand focused
  Rust/frontend tests.
- Bootstrap Trellis project guidance and refresh product, design, architecture,
  release-process, and optimization documentation.

#### Packages

- `latest.json`
- `skillport_0.10.10_windows_x64_nsis.exe`
- `skillport_0.10.10_windows_x64_nsis.exe.sig`
- `skillport_0.10.10_windows_x64.msi`
- `skillport_0.10.10_windows_x64.zip`
- `skillport_0.10.10_macos_universal.dmg`
- `skillport_0.10.10_macos_universal.zip`
- `skillport_0.10.10_macos_universal.tar.gz`
- `skillport_0.10.10_linux_x86_64.deb`
- `skillport_0.10.10_linux_x86_64.rpm`
- `skillport_0.10.10_linux_x86_64.AppImage`

#### Notes

- Built-in app updates remain Windows x64 only because `latest.json` contains
  Windows updater metadata only.
- macOS packages are still not notarized.
- Linux packages are published as install artifacts, not as built-in updater
  targets.

## 0.10.0

### English

SkillPort 0.10.0 aligns this Windows-first fork with the upstream 0.10.0 release line while keeping the fork identity, private Central path, and installer-oriented release contract intact.

#### Highlights

- Add Linux desktop packaging metadata and release jobs for `.deb`, `.rpm`, and `.AppImage`.
- Keep Windows release coverage with NSIS `.exe`, `.msi`, and portable `.zip`.
- Forward Discover install mode selection so project skills can be installed to platforms via `symlink` or `copy`.
- Deduplicate shared Discover platform patterns like `.agents/skills` to reduce repeated matches during scans.
- Delete tracked `.factory/` factory artifacts and ignore future `.factory/` output without hiding `AGENTS.md`.

#### Packages

- `skillport_0.10.0_windows_x64_nsis.exe`
- `skillport_0.10.0_windows_x64.msi`
- `skillport_0.10.0_windows_x64.zip`
- `skillport_0.10.0_macos_universal.dmg`
- `skillport_0.10.0_macos_universal.zip`
- `skillport_0.10.0_macos_universal.tar.gz`
- `skillport_0.10.0_linux_x86_64.deb`
- `skillport_0.10.0_linux_x86_64.rpm`
- `skillport_0.10.0_linux_x86_64.AppImage`
- `skillport_0.10.0_linux_arm64.deb`
- `skillport_0.10.0_linux_arm64.rpm`
- `skillport_0.10.0_linux_arm64.AppImage`

#### Notes

- Linux package metadata uses the fork identity: `SkillPort`, `skillport`, and `com.bahayonghang.skillport`.
- The app still keeps Central Skills in `~/.skillsmanage/skills` instead of moving back to the shared `~/.agents/skills` directory.
- Desktop builds remain unsigned, macOS notarization is still pending, and Linux arm64 runner availability is best-effort in GitHub Actions.

### 中文

- 删除已跟踪的 `.factory/` 工厂产物，并忽略后续 `.factory/` 输出，同时不隐藏 `AGENTS.md`。

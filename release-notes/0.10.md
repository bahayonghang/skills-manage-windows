# SkillPort 0.10.x

## 0.10.9

### English

SkillPort 0.10.9 is the first Windows updater release for this fork. It keeps the existing desktop package matrix while publishing signed Windows NSIS updater metadata through `latest.json`.

#### Highlights

- Publish Windows updater metadata as `latest.json` from the tag-based `Release Desktop` workflow.
- Sign the Windows NSIS updater artifact with Tauri updater keys stored in GitHub Actions secrets.
- Keep Windows installer coverage with NSIS `.exe`, MSI, and portable `.zip`.
- Continue publishing macOS Universal and Linux desktop packages as regular install artifacts.

#### Packages

- `latest.json`
- `skillport_0.10.9_windows_x64_nsis.exe`
- `skillport_0.10.9_windows_x64_nsis.exe.sig`
- `skillport_0.10.9_windows_x64.msi`
- `skillport_0.10.9_windows_x64.zip`
- `skillport_0.10.9_macos_universal.dmg`
- `skillport_0.10.9_macos_universal.zip`
- `skillport_0.10.9_macos_universal.tar.gz`
- `skillport_0.10.9_linux_x86_64.deb`
- `skillport_0.10.9_linux_x86_64.rpm`
- `skillport_0.10.9_linux_x86_64.AppImage`

#### Notes

- Built-in app updates are Windows x64 only in this release because `latest.json` contains Windows updater metadata only.
- macOS packages are still not notarized.
- Linux packages are published as install artifacts, not as built-in updater targets.

## 0.10.0

### English

SkillPort 0.10.0 aligns this Windows-first fork with the upstream 0.10.0 release line while keeping the fork identity, private Central path, and installer-oriented release contract intact.

#### Highlights

- Add Linux desktop packaging metadata and release jobs for `.deb`, `.rpm`, and `.AppImage`.
- Keep Windows release coverage with NSIS `.exe`, `.msi`, and portable `.zip`.
- Forward Discover install mode selection so project skills can be installed to platforms via `symlink` or `copy`.
- Deduplicate shared Discover platform patterns like `.agents/skills` to reduce repeated matches during scans.
- Delete tracked `.factory/` factory artifacts and ignore future `.factory/` output without hiding `AGENTS.md`.

#### Packages

- `skillport_0.10.0_windows_x64_nsis.exe`
- `skillport_0.10.0_windows_x64.msi`
- `skillport_0.10.0_windows_x64.zip`
- `skillport_0.10.0_macos_universal.dmg`
- `skillport_0.10.0_macos_universal.zip`
- `skillport_0.10.0_macos_universal.tar.gz`
- `skillport_0.10.0_linux_x86_64.deb`
- `skillport_0.10.0_linux_x86_64.rpm`
- `skillport_0.10.0_linux_x86_64.AppImage`
- `skillport_0.10.0_linux_arm64.deb`
- `skillport_0.10.0_linux_arm64.rpm`
- `skillport_0.10.0_linux_arm64.AppImage`

#### Notes

- Linux package metadata uses the fork identity: `SkillPort`, `skillport`, and `com.bahayonghang.skillport`.
- The app still keeps Central Skills in `~/.skillsmanage/skills` instead of moving back to the shared `~/.agents/skills` directory.
- Desktop builds remain unsigned, macOS notarization is still pending, and Linux arm64 runner availability is best-effort in GitHub Actions.

### 中文

SkillPort 0.10.0 在保持当前 fork 身份、私有 Central 路径和 Windows-first 安装包发布契约的前提下，对齐上游 0.10.0 的关键发布能力。

#### 亮点

- 新增 Linux 桌面打包 metadata 和 release job，可产出 `.deb`、`.rpm`、`.AppImage`。
- 保留 Windows 发布覆盖，继续准备 NSIS `.exe`、`.msi` 和便携 `.zip`。
- Discover 安装项目技能到平台时，支持把安装模式透传为 `symlink` 或 `copy`。
- 对共享 Discover 模式（如 `.agents/skills`）做去重，减少扫描时的重复平台匹配。
- 删除已跟踪的 `.factory/` 工厂产物，并忽略后续 `.factory/` 输出，同时不隐藏 `AGENTS.md`。

#### 安装包

- `skillport_0.10.0_windows_x64_nsis.exe`
- `skillport_0.10.0_windows_x64.msi`
- `skillport_0.10.0_windows_x64.zip`
- `skillport_0.10.0_macos_universal.dmg`
- `skillport_0.10.0_macos_universal.zip`
- `skillport_0.10.0_macos_universal.tar.gz`
- `skillport_0.10.0_linux_x86_64.deb`
- `skillport_0.10.0_linux_x86_64.rpm`
- `skillport_0.10.0_linux_x86_64.AppImage`
- `skillport_0.10.0_linux_arm64.deb`
- `skillport_0.10.0_linux_arm64.rpm`
- `skillport_0.10.0_linux_arm64.AppImage`

#### 说明

- Linux 安装包 metadata 使用 fork 身份：`SkillPort`、`skillport`、`com.bahayonghang.skillport`。
- 中央技能库仍保持在 `~/.skillsmanage/skills`，不会回退到共享 `~/.agents/skills`。
- 当前桌面构建仍未签名，macOS notarization 仍待后续处理；Linux arm64 runner 在 GitHub Actions 中按 best-effort 提供。

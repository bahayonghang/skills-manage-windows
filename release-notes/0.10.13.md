# SkillPort 0.10.13

### English

SkillPort 0.10.13 refreshes the desktop identity and makes typography settings
more practical across light and dark themes.

#### Highlights

- Add separate Display and Body font preferences for light and dark themes,
  while preserving existing font choices during migration.
- Add independently configurable Chinese fallback fonts and custom family
  values without bundling additional font files.
- Rework the Appearance typography controls into a denser, clearer layout with
  explicit light/dark editing context and responsive behavior.
- Simplify Settings sections around a shared structure for more consistent
  navigation, spacing, and interaction states.
- Replace the SkillPort application icon across Windows, macOS, iOS, and
  Android asset sets.
- Keep the release metadata synchronized at `0.10.13` across package, Tauri,
  and Cargo manifests.

- Linux packages are published as install artifacts, not as built-in updater
  targets.

### 中文

SkillPort 0.10.13 更新了桌面端品牌图标，并让亮色、暗色主题下的字体设置
更清晰、更实用。

#### 亮点

- 为亮色和暗色主题分别保存 Display 与 Body 字体偏好，并在升级时继承已有
  字体设置。
- 新增可独立配置的中文 fallback 字体和自定义字体族，不额外打包字体文件。
- 重构 Appearance 中的字体控件，以更紧凑、清晰的布局明确当前编辑的亮色或
  暗色配置，并保持响应式行为。
- 围绕共享结构简化 Settings section，使导航、间距和交互状态更加一致。
- 替换 Windows、macOS、iOS 与 Android 全套 SkillPort 应用图标。
- 将 package、Tauri 与 Cargo manifest 中的发布 metadata 同步到 `0.10.13`。

  Windows updater metadata。
- macOS 安装包仍未 notarize。
- Linux 安装包作为普通安装产物发布，不作为应用内 updater 目标。

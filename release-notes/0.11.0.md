# SkillPort 0.11.0

## English

SkillPort 0.11.0 is the `0.10.x → 0.11.0 secret store consolidation` release. It focuses on removing plaintext secret writes from settings while keeping the Windows-first packaging contract unchanged.

### Highlights

- GitHub PAT now uses the shared SecretStore path instead of plaintext SQLite settings.
- AI API Key now uses SecretStore; non-sensitive AI settings still use normal settings.
- Legacy `github_pat` and `ai_api_key` rows migrate only after the new secret can be written and read back successfully.
- Generic settings IPC rejects protected secret keys to prevent accidental plaintext regressions.
- Settings store actions now use the shared `@/lib/tauri` runtime wrapper for consistent browser fixtures.
- SKILL.md frontmatter parsing moved from unmaintained `serde_yaml` to `serde_norway`.

### Upgrade notes

- Existing GitHub PAT and AI API Key values are migrated on startup when the secure store is available.
- If secure storage fails during migration, the legacy value is kept as a compatibility fallback and the migration marker is not written.
- Saved secrets are no longer echoed back into the Settings UI after a successful save.
- This release does not change installer names, bundle targets, signing state, or Windows output paths.

### Validation focus before publishing

- Run `just ci` before tagging.
- Because this release changes secret storage, manually check save, clear, and test flows for GitHub PAT and AI API Key on Windows.
- Before an actual release build, run `pnpm tauri build` on Windows and confirm the NSIS artifact is generated.

## 中文

SkillPort 0.11.0 是 `0.10.x → 0.11.0 secret store consolidation` 安全收口版本，重点是移除 settings 中的明文 secret 写入，同时保持 Windows-first 打包契约不变。

### 亮点

- GitHub PAT 改走统一 SecretStore，不再写入 SQLite settings 明文。
- AI API Key 改走 SecretStore；非敏感 AI 设置仍继续使用普通 settings。
- 旧版 `github_pat` 与 `ai_api_key` 行只会在新 secret 写入并读回成功后迁移。
- generic settings IPC 会拒绝受保护 secret key，避免误把敏感值重新写回明文 settings。
- Settings store action 统一使用 `@/lib/tauri` runtime 封装，浏览器 fixture 行为与其他 store 保持一致。
- SKILL.md frontmatter 解析从 unmaintained `serde_yaml` 切换到 `serde_norway`。

### 升级说明

- 已保存的 GitHub PAT 和 AI API Key 会在启动时尝试迁移到安全存储。
- 如果迁移时安全存储不可用，旧值会保留为兼容 fallback，且不会写入迁移标记。
- secret 保存成功后，Settings UI 不再回显输入的敏感值。
- 本版本不改变安装包命名、bundle target、签名状态或 Windows 输出路径。

### 发布前验证重点

- 打 tag 前先运行 `just ci`。
- 由于本版本修改了 secret 存储，需要在 Windows 上手工确认 GitHub PAT 与 AI API Key 的保存、清除、测试流程。
- 真正发布前，在 Windows 上运行 `pnpm tauri build` 并确认 NSIS 产物已生成。

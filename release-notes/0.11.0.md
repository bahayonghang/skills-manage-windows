# SkillPort 0.11.0

## English

SkillPort 0.11.0 is the Central Library V2 and secret-store consolidation release. It makes the new Central Skills information architecture the default while keeping the Windows-first installer and release contract unchanged.

### Highlights

- **Central Library V2 is now the default**: Smart Views, repositories, tags, saved views, search, sorting, grouping, and command-palette actions live in one workspace.
- **Structured search** supports `tag:`, `repo:`, `owner:`, `source:`, `has:`, `platform:`, `created:`, and `updated:` filters. Search keys are case-insensitive and filter values preserve casing.
- **URL-as-state** keeps query text, selected facets, sorting, grouping, view mode, and saved-view identity shareable through the URL query string.
- **Saved Views** persist common Central queries and can be opened from the sidebar or `Ctrl+K`.
- **Tag Groups** organize large tag sets without moving skill files; tags can be assigned or removed from a group in the V2 sidebar.
- **Group-by views** cover no grouping, repository, owner, tag, and update status.
- **Command palette actions** can save the current view, create tag groups, switch grouping mode, or return to the classic layout.
- GitHub PAT and AI API Key now use the shared SecretStore path instead of plaintext SQLite settings.
- SKILL.md frontmatter parsing moved from unmaintained `serde_yaml` to `serde_norway`.

### Upgrade notes

- Central Library V2 opens by default. Use **Switch to classic layout** near the V2 badge if you need the previous layout during rollout.
- Developers can set `featureFlag.central.newLayout=off` in DevTools localStorage and dispatch `feature-flag-change` to force the classic layout.
- Saved Views and Tag Groups are local metadata. Deleting them does not delete skills or move skill folders.
- Existing GitHub PAT and AI API Key values are migrated on startup when secure storage is available.
- If secure storage fails during migration, the legacy value is kept as a compatibility fallback and the migration marker is not written.
- Saved secrets are no longer echoed back into the Settings UI after a successful save.
- This release does not change installer names, bundle targets, signing state, or Windows output paths.

### Known gaps

- Drag-and-drop reorder UI for Saved Views and Tag Groups is deferred. Backend reorder IPC and store actions are already present.
- Saved View and Tag Group create/rename/delete flows still use lightweight prompt/confirm dialogs until a dedicated dialog primitive is introduced.
- Backend FTS5 search remains deferred until the Central library exceeds the planned size/latency threshold.

### Validation focus before publishing

- Run `just ci` before tagging.
- Run `pnpm docs:build` after docs or changelog edits.
- Because this release changes secret storage, manually check save, clear, and test flows for GitHub PAT and AI API Key on Windows.
- Before an actual release build, run `pnpm tauri build` on Windows and confirm the NSIS artifact is generated.

## 中文

SkillPort 0.11.0 是中央技能库 V2 与 secret store consolidation 收口版本。它让新的 Central Skills 信息架构默认开启，同时保持 Windows-first 安装包和发布契约不变。

### 亮点

- **中央技能库 V2 默认开启**：Smart Views、仓库、标签、保存视图、搜索、排序、分组和命令面板动作集中在一个工作区。
- **结构化搜索**支持 `tag:`、`repo:`、`owner:`、`source:`、`has:`、`platform:`、`created:`、`updated:`。搜索 key 大小写不敏感，value 保留原始大小写。
- **URL-as-state** 会把查询词、已选 facet、排序、分组、视图模式和 saved-view 身份写入 URL query，方便分享和恢复。
- **Saved Views** 可保存常用 Central 查询，并从侧边栏或 `Ctrl+K` 打开。
- **Tag Groups** 可整理大量标签，且不会移动 skill 文件；V2 侧边栏可直接把 tag 分配到分组或移出分组。
- **Group-by 视图** 支持不分组、按仓库、按 owner、按标签、按更新状态分组。
- **命令面板动作** 可保存当前视图、创建标签分组、切换分组模式，或退回经典布局。
- GitHub PAT 与 AI API Key 改走统一 SecretStore，不再写入 SQLite settings 明文。
- SKILL.md frontmatter 解析从 unmaintained `serde_yaml` 切换到 `serde_norway`。

### 升级说明

- 中央技能库 V2 会默认打开。rollout 期间如需旧版界面，可点击 V2 徽章附近的 **切回经典布局**。
- 开发者也可以在 DevTools localStorage 中设置 `featureFlag.central.newLayout=off`，再派发 `feature-flag-change` 强制使用经典布局。
- Saved Views 与 Tag Groups 都是本地元数据。删除它们不会删除 skills，也不会移动 skill 文件夹。
- 已保存的 GitHub PAT 和 AI API Key 会在启动时尝试迁移到安全存储。
- 如果迁移时安全存储不可用，旧值会保留为兼容 fallback，且不会写入迁移标记。
- secret 保存成功后，Settings UI 不再回显输入的敏感值。
- 本版本不改变安装包命名、bundle target、签名状态或 Windows 输出路径。

### 已知缺口

- Saved Views 与 Tag Groups 的拖拽排序 UI 延后；后端 reorder IPC 与 store action 已就绪。
- Saved View 与 Tag Group 的创建、重命名、删除仍使用轻量 prompt/confirm，后续再接专用 Dialog primitive。
- 后端 FTS5 搜索继续延后到 Central 技能规模或过滤耗时达到触发阈值之后。

### 发布前验证重点

- 打 tag 前先运行 `just ci`。
- 修改 docs 或 changelog 后运行 `pnpm docs:build`。
- 由于本版本修改了 secret 存储，需要在 Windows 上手工确认 GitHub PAT 与 AI API Key 的保存、清除、测试流程。
- 真正发布前，在 Windows 上运行 `pnpm tauri build` 并确认 NSIS 产物已生成。

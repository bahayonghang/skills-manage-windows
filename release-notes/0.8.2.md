# skills-manage 0.8.2

## 中文

面向 Windows 构建链路和大列表体验的补丁版本。

### 亮点

- 启动时先读取缓存快照，先展示平台、集合和 Discover 计数，再后台刷新扫描结果
- 中央技能库和平台技能库的大卡片列表改成虚拟网格，减少滚动和筛选时的重渲染
- 扫描缓存按目录归并，避免多个平台指向同一目录时重复写库或留下旧安装记录
- Discover 新增 summary 接口，侧边栏角标和轻量刷新不再拉取整份项目结果
- 平台页改成按需加载中央技能库，只有打开安装弹窗时才取安装目标

## English

Patch release focused on Windows packaging readiness, cached shell hydration, and large-list performance.

### Highlights

- Render the shell from a cached bootstrap snapshot before the background scan so platform, collection, and Discover counts appear immediately
- Virtualize large central and platform skill grids to reduce scroll and filter re-render cost
- Collapse shared scan roots across platforms so rescans update cached installations without leaving stale rows behind
- Add a lightweight Discover summary endpoint so sidebar badges and refresh flows no longer fetch full project results just to refresh counters
- Load central skills on demand when the platform install dialog opens instead of preloading them on every platform page visit

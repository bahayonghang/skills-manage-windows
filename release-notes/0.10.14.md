# SkillPort 0.10.14

### English

SkillPort 0.10.14 strengthens skill portability, local automation, GitHub
imports, and usage analytics across the Windows-first desktop workflow.

#### Highlights

- Add stable skill identities, serialized central-store mutations, and a
  shared local `skillport-cli` for reliable automation outside the desktop UI.
- Treat equivalent Windows short and long paths consistently across skill
  discovery, linking, imports, and portable-state workflows.
- Fix Tauri desktop packaging in the multi-binary Rust workspace by selecting
  the intended desktop entry point explicitly.
- Add bilingual CLI reference documentation covering commands, JSON output,
  exit codes, locking behavior, and PowerShell usage.
- Import repositories whose root is itself a skill, including complete root
  content instead of only nested skill directories.
- Rework skill usage analytics with richer aggregation, activity heatmaps,
  filtering, recent calls, and per-skill detail views.
- Add a selectable file-tree preview to the GitHub import flow so users can
  inspect repository contents before importing.
- Keep the release metadata synchronized at `0.10.14` across package, Tauri,
  and Cargo manifests.

### 中文

SkillPort 0.10.14 围绕 Windows-first 桌面工作流，增强了技能可移植性、本机
自动化、GitHub 导入和使用统计能力。

#### 亮点

- 新增稳定技能标识、中央仓库变更串行锁，以及可在桌面 UI 之外调用的共享本机
  `skillport-cli`，提升自动化可靠性。
- 在技能发现、链接、导入和可移植状态工作流中统一识别等价的 Windows 短路径与
  长路径。
- 在包含多个 Rust binary 的工作区中显式指定桌面入口，修复 Tauri 桌面打包。
- 新增中英文 CLI 参考文档，覆盖命令、JSON 输出、退出码、锁行为和 PowerShell
  用法。
- 支持导入仓库根目录本身就是 skill 的项目，完整同步根级内容，而不再只处理嵌套
  skill 目录。
- 重构技能使用统计，补充聚合指标、活动热力图、筛选、最近调用和单技能详情视图。
- 为 GitHub 导入流程新增可选择的文件树预览，导入前即可检查仓库内容。
- 将 package、Tauri 与 Cargo manifest 中的发布 metadata 同步到 `0.10.14`。

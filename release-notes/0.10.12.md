# SkillPort 0.10.12

### English

SkillPort 0.10.12 is a stabilization and polish release for the Windows-first
desktop line. It ships the accumulated architecture hardening, UI refinement,
platform-source visibility, and release-readiness work after `v0.10.10`.

#### Highlights

- Add a platform install-source quick navigation bar so platform views can be
  filtered by local, project, central, marketplace, and remote origins.
- Surface Central Skills update-check failures in the UI instead of silently
  losing failed refresh state.
- Refine dashboard density, semantic status colors, keyboard focus treatment,
  shortcut discovery, and card interaction feedback.
- Move Central Updates and central store-location behavior into service-domain
  modules with typed errors, snapshots, inventory helpers, and focused tests.
- Introduce a typed frontend IPC adapter and browser fixture seam, replacing
  scattered direct invoke usage in stores and tests.
- Consolidate platform grouping and install-dialog multi-select behavior around
  shared registry/view-model helpers.
- Centralize remote path handling, installation command execution, SKILL.md
  frontmatter parsing, redaction policy, and Rust test fixtures.
- Keep the release metadata synchronized at `0.10.12` across package, Tauri,
  and Cargo manifests.

### 中文

SkillPort 0.10.12 是 Windows-first 桌面线的一次稳定性与体验打磨版本，
集中发布了 `v0.10.10` 之后积累的架构加固、界面优化、平台来源可见性和
发布准备工作。

#### 亮点

- 新增平台安装来源快速导航栏，可按本地、项目、中央库、市场和远程来源筛选
  平台视图。
- 中央技能库更新检查失败会在界面中明确提示，不再静默丢失刷新失败状态。
- 打磨 dashboard 信息密度、语义状态色、键盘焦点、快捷键入口和卡片交互反馈。
- 将 Central Updates 与中央库位置迁移逻辑收拢到 service-domain 模块，并补齐
  typed errors、snapshot、inventory helper 和定向测试。
- 引入类型化前端 IPC adapter 与浏览器 fixture seam，替代 store 和测试里的
  分散 direct invoke 用法。
- 围绕共享 registry / view-model helper 收敛平台分组与安装对话框多选行为。
- 统一远程路径处理、安装命令执行、SKILL.md frontmatter 解析、脱敏策略和
  Rust 测试 fixture。
- 将 package、Tauri 与 Cargo manifest 中的发布 metadata 保持同步到 `0.10.12`。

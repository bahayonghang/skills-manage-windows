# SkillPort 0.9.x

## 0.9.6

### English

This patch release republishes the 0.9.5 desktop build with release workflow fixes.

#### Highlights

- Re-run the desktop release flow after hardening GitHub Actions on Windows runners.
- Keep CI independent from a preinstalled `just` binary by running the same repository checks directly in Actions.
- Allow the desktop release publisher to fall back to an existing GitHub Release body when local release notes are missing.
- Include the 0.9.5 release notes in the repository so the release metadata is complete.

#### Packages

- `skillport_0.9.6_windows_x64_nsis.exe`
- `skillport_0.9.6_windows_x64.msi`
- `skillport_0.9.6_windows_x64.zip`
- `skillport_0.9.6_macos_universal.dmg`
- `skillport_0.9.6_macos_universal.zip`
- `skillport_0.9.6_macos_universal.tar.gz`

#### Notes

- Product-facing changes are the same feature set introduced in 0.9.5: local operation logs, Dashboard, and Claude Light / Claude Dark themes.
- This release avoids moving the already published `v0.9.5` tag.
- Desktop builds remain unsigned, and macOS notarization is still deferred.

#### Verification

- `just ci`

## 0.9.5

### English

This release adds local operation history, a dashboard entry point, and Claude-inspired light and dark themes.

#### Highlights

- Add a local operation log system backed by the existing SQLite database, including query, detail, export, clear, and filter flows.
- Add Dashboard as the default entry point for target status, Central status, pending work, and recent local operations.
- Add Claude Light and Claude Dark themes with persisted theme selection.
- Record key operations on a best-effort basis so logging failures do not block the main user action.
- Keep Dashboard quick actions as navigation-only shortcuts.
- Extend tests for dashboard, logs, navigation, theme, and settings behavior.

#### Packages

- `skillport_0.9.5_windows_x64_nsis.exe`

## 0.9.0

### English

Cross-platform improvement release focused on Windows support, universal macOS packaging, and reliability fixes across installs, rescans, and source-specific skill detail flows.

#### Highlights

- Added **Windows x64** support with `.msi` and portable `.zip` packages
- Upgraded macOS packaging to **universal** `.dmg`, `.zip`, and `.tar.gz` outputs
- Improved Windows/macOS path handling and install reliability
- Preserved Claude source-specific continuity across platform rows, detail views, and explanations
- Shipped rescan refresh fixes plus a round of small UI/accessibility polish

#### Packages

- `skills-manage_0.9.0_windows_x64.msi`
- `skills-manage_0.9.0_windows_x64.zip`
- `skills-manage_0.9.0_macos_universal.dmg`
- `skills-manage_0.9.0_macos_universal.zip`
- `skills-manage_0.9.0_macos_universal.tar.gz`

#### Notes

- Windows installs can automatically fall back from symlink to copy when symlink creation is unavailable.
- Current desktop builds are unsigned, and macOS notarization is still deferred.
- Checksums should be generated from the final release artifacts before publishing or mirroring builds.

#### Changelog

- Added Windows-aware home expansion and cross-platform path rendering in backend commands and frontend views
- Added Windows-friendly install fallback from symlink to copy for skill distribution
- Added GitHub Actions desktop packaging flows for Windows x64 and macOS universal builds
- Fixed Claude multi-source continuity across source-specific rows, detail actions, and explanation loading
- Fixed rescan refresh propagation so central, platform, and discover surfaces stay aligned after full rescans
- Polished settings, sidebar, drawer, and path display interactions with additional accessibility and test coverage

## 反模式判定

**LLM 评估**：可信，不 slop。等宽正文、Catppuccin/Claude token 换肤、`transition-[具体属性]` + `active:scale-[0.96]` 纪律是"有人在认真做决定"的信号。三处陈腐风险：MetricStrip（最接近无差别 SaaS metric 网格，靠可点击 + tabular-nums 站在线内）、SourceMeta 彩虹（唯一像未加考虑默认值的地方）、readiness 大分数（DESIGN 授权的合法重场景，执行克制，站在正确一侧）。

**确定性扫描**：detect.mjs 退出码 2，20 处命中 / 4 类规则，约 14 处误报（测试 fixture、字体选择器预览、pill 惯用法、scrollbar 伪元素）。**主产品面零命中**。真实命中：index.css:59 `.startup-card` 圆角 24px 超 14px 封顶（强）；index.css:1067 inline-code chip 7.2px 近 token 漂移（弱）；index.css:79 闪屏渐变含未登记 #89b4fa（弱）。**两个评估交叉印证**：检测器证明 token 体系在主界面执行干净，与 LLM"失分在人工层面的一致性而非 token 违规"的判断一致。

**浏览器可视化**：跳过——本会话无浏览器自动化工具，且 Tauri 应用数据层依赖 IPC，纯浏览器无法真实渲染。

## 总体印象

一套认真兑现了自身设计意图的界面，远非 AI 套模板。最大机会：把**一致性**（Nielsen #4 唯一 2 分的工艺项）提上来——两套卡片惯用法、两套按压语言、焦点环覆盖不均，全是"多人多时期手笔"的自然漂移，收敛成本低、收益直接。

## 优先问题（已全部核实 file:line）

- **[P1] SourceMeta 彩虹色绕过 token 体系**：`SourceMeta.tsx:25-51` 四类字段涂 sky/emerald/cyan/violet + `dark:` 二元适配，违反 statusTone.ts:14 明令；固定色相不随 6 主题换肤；字段类型≠状态。修：统一 cache 行中性样板（:41-45），字段区分靠标签文字。
- **[P1] 核心交互按钮焦点环缺失**：`focus-visible:` 仅 18 文件；平台 toggle（UnifiedSkillCardFooter.tsx:38-61）、卡片图标动作（UnifiedSkillCard.tsx:603,786）、dashboard 磁贴、InlineConfirm 两键均无显式焦点环。装/卸技能是最高频操作，纯键盘会丢焦点。修：共享 focus ring 工具类。
- **[P2] toggle 安装态颜色单独编码 + 低对比**：`UnifiedSkillCardFooter.tsx:40-45` 未装 `text-muted-foreground/40` vs 已装 `text-primary`，违反 Color-Is-Never-Alone。修：提对比 + 加形状差异。
- **[P2] 圆角越界 + border 代 ring 第二套惯用法**：dashboard ×7 `rounded-3xl`(22px)；Settings `rounded-[1.5rem/1.6rem]`(24-25.6px) 超硬红线；`rounded-2xl+border` 成片（AppearanceSettingsSection ×10 等）。修：收敛或 DESIGN.md 登记例外。
- **[P2] dashboard 外装饰性玻璃**：`AppearanceSettingsSection.tsx:169` 静态卡 backdrop-blur+shadow-2xl 越界 Glass-Is-Earned；`BulkActionBar.tsx:64` 浮条需决策。
- **[P2] Dialog 关闭键硬编码英文**：`dialog.tsx:79,117` "Close" 绕过 i18n，中文 locale 屏幕阅读器读英文。
- **[P3] 两套按压语言 + scale 漂移**：Button `translate-y-px` vs 手写 `scale-[0.96]`（35+ 处）；漂移 95×4、0.98×2、0.99×1。
- **[P3] `transition-all` ×3**：SettingsSideNav.tsx:40、AboutSettingsSection.tsx:323、CentralStatePortabilityDialog.tsx:423。
- **[P3] 10px 大写信息标签**（Sidebar.tsx:306,332、UnifiedSkillCard.tsx:478,691,812 等）触可读性地板。
- **[P3] `statusAccent?: "amber"|"red"`**（UnifiedSkillCard.tsx:99,232）原生色名做 API 判别值。
- **[P3] MetricStrip** 4 张等权大数字卡最接近反面清单（需产品决策）。

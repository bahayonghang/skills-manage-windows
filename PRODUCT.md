# Product

## Register

product

## Users

Developers and power users who manage local AI coding agent skills across several tools. They work in desktop workflows, often on Windows, and need to see what exists, where it is installed, and which operations will touch local or remote skill directories.

## Product Purpose

SkillPort is a local-first Tauri desktop app for managing a private Central skills library, installing selected skills into platform-specific directories, browsing marketplace metadata, importing GitHub skill repositories, organizing collections, and managing remote SSH targets without hiding filesystem boundaries.

## Brand Personality

Calm, precise, trustworthy.

The interface should feel like a dependable local operations console: dense enough for expert workflows, cautious around destructive actions, and explicit about storage, target, and platform state.

## Anti-references

Do not look like a generic SaaS dashboard, a marketplace landing page, or a decorative AI-themed command center. Avoid hero metrics, ornamental gradients, glass cards, vague empty states, and hidden background automation for operations users must review.

## Design Principles

1. Make filesystem and target boundaries visible before action.
2. Prefer reviewable workflows over hidden background magic.
3. Keep controls familiar and dense enough for daily expert use.
4. Treat Windows packaging and local data compatibility as product constraints.
5. Surface privacy and network side effects plainly.

## Accessibility & Inclusion

Aim for WCAG AA. Preserve keyboard access for dialogs, lists, search, destructive actions, and settings. Support dark and light Catppuccin themes without relying on color alone for status. Respect reduced-motion expectations and keep touch targets usable on narrow windows.
